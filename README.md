# 가면의 원탁

오프라인 모임에서 함께 접속해 진행하는 익명 어젠더 나눔 게임.

- 진행자: 페이지를 열고 "진행자로 모임 만들기" → QR·링크로 참가자 초대
- 참가자: 가명과 어젠더를 적고 입장 → 어젠더마다 생각·조언·질문을 익명으로 작성 → 공개 후 공감 → "내가 어젠더 주인이라면…" 나눔
- 마무리: 어젠더 다시 보기 → 주제별 공감 받은 의견 → 오늘의 공감왕 → 내가 얻은 성찰
- 모든 데이터는 진행자 브라우저에만 있고 참가자와 P2P로 연결됩니다. 서버에 저장하지 않습니다.
- 주소 뒤에 `?demo`를 붙이면 한 브라우저의 여러 탭으로 연습할 수 있습니다.
