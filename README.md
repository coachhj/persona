# 가면의 원탁

온/오프라인 모임에서 함께 접속해 진행하는 익명 어젠더 나눔 게임.

- 진행자: 페이지를 열고 "진행자로 모임 만들기" → QR·링크로 참가자 초대
- 참가자: 가명과 어젠더를 적고 입장 → 어젠더마다 생각·조언·질문을 익명으로 작성 → 공개 후 공감 → "내가 어젠더 주인이라면…" 나눔
- 마무리: 어젠더 다시 보기 → 주제별 공감 받은 의견 → 오늘의 공감왕 → 내가 얻은 성찰, 그리고 계획
- 연결은 Firebase Realtime Database(halligalli 프로젝트의 `mask/` 경로)를 우편함처럼 거칩니다. 모든 기록은 진행자 브라우저에만 있고, 메시지는 받는 즉시 지워지며 모임을 닫으면 방도 삭제됩니다.
